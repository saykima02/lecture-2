목표

흩어진 파일을

여기서 만든 폴더를 2교시에 그대로 올립니다.

순서

  1. 1Claude 탭 새 대화 → 입력창에서 '부서포털' 폴더 추가 → 접근 허용
  2. 2아래 프롬프트로 폴더 정리 요청
  3. 3탐색기에서 index.html · files/ · README.md가 생겼는지 눈으로 확인
  4. 4index.html을 더블클릭해 브라우저에서 열어 보기
실습이 폴더의 부서포털_v2.html을 index.html로 이름을 바꾸고(원본 사본은 '이전버전' 폴더에 보관), PDF·Word 파일은 files 폴더로 옮겨 줘. 파일명은 한글·공백 없이 영문 소문자와 하이픈으로 바꾸고, 포털 사용법을 README.md로 작성해 줘. index.html 안의 링크도 바뀐 파일명으로 모두 고쳐 줘.

끝나면 확인

  • 폴더에 index.html이 있다
  • files 폴더 안에 자료가 들어갔다
  • 파일명이 전부 영문 소문자·하이픈이다
  • 브라우저로 열었을 때 1강 화면이 그대로 나온다
주의
  • '이전버전' 폴더는 2교시에 올리지 않습니다

6. (선택) 편의 기능

빨리 끝내신 분을 위한 추가 과제

시간이 남을 때만
모바일 ≡ 메뉴
휴대폰에서 상단 메뉴가 길게 늘어지지 않도록 햄버거 버튼으로 접습니다.
실습모바일에서는 상단 메뉴가 햄버거(≡) 버튼으로 접히고, 메뉴 항목을 누르면 자동으로 닫히게 다듬어 줘. 지금 보고 있는 영역의 메뉴가 강조되게 해 줘.
다크모드 · 맨 위로
눈이 편한 어두운 화면 전환 버튼과, 길게 스크롤했을 때 맨 위로 올라가는 버튼.
실습다크모드 전환 버튼과 '맨 위로' 버튼을 추가해 줘.
계산기 · 체크리스트

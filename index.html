실습 · 1. 폴더 정리

폴더를 연결하고 공개용 구조로 바꾸기

실습 15분폴더 연결

목표

흩어진 파일을
공개해도 되는
폴더 구조로
한 번에 정리
여기서 만든 폴더를 2교시에 그대로 올립니다.

순서

  1. 1Claude 탭 새 대화 → 입력창에서 '부서포털' 폴더 추가 → 접근 허용
  2. 2아래 프롬프트로 폴더 정리 요청
  3. 3탐색기에서 index.html · files/ · README.md가 생겼는지 눈으로 확인
  4. 4index.html을 더블클릭해 브라우저에서 열어 보기
이 폴더의 부서포털_v2.html을 index.html로 이름을 바꾸고(원본 사본은 '이전버전' 폴더에 보관), PDF·Word 파일은 files 폴더로 옮겨 줘. 파일명은 한글·공백 없이 영문 소문자와 하이픈으로 바꾸고, 포털 사용법을 README.md로 작성해 줘. index.html 안의 링크도 바뀐 파일명으로 모두 고쳐 줘.

끝나면 확인

  • 폴더에 index.html이 있다
  • files 폴더 안에 자료가 들어갔다
  • 파일명이 전부 영문 소문자·하이픈이다
  • 브라우저로 열었을 때 1강 화면이 그대로 나온다
주의
  • '이전버전' 폴더는 2교시에 올리지 않습니다

다크모드 · 맨 위로
눈이 편한 어두운 화면 전환 버튼과, 길게 스크롤했을 때 맨 위로 올라가는 버튼.
다크모드 전환 버튼과 '맨 위로' 버튼을 추가해 줘.
계산기 · 체크리스트
부서 업무에 맞는 간단한 도구. 입력값은 브라우저 안에서만 계산되고 저장되지 않습니다.
○○를 입력하면 △△를 보여 주는 간단한 계산기를 넣어 줘. 입력 내용은 저장하거나 외부로 보내지 마.
